### Internal Assessment: Managerial Economics Report

This repository contains the source code for my internal assessment for the **Managerial Economics** course, under the guidance of **Prof. Gauri Apte**. The project is a single-page interactive infographic designed to present complex economic concepts in a clear and visually engaging format.

---

### Project Overview

This report provides a detailed analysis of:

* **Price Elasticity of Demand (PED):** Examining the elasticity for a range of commodities and services, and the impact of price changes on each.
* **Tariffs and Trade:** Commenting on the effects of tariffs on foreign demand, considering the role of elasticity.
* **Government Intervention:** Discussing the various ways governments intervene in markets, including the use of tariffs.

The infographic is built to be dynamic, with interactive elements that highlight key data and provide a more immersive user experience.
